)

Q26. Grade
def grade(x):
    if x>=90: return "A+"
    elif x>=80: return "A"
    elif x>=70: return "B"
    elif x>=60: return "C"
    else: return "D"

df["Grade"] = df["Marks"].apply(grade)
print(df[["Name","Marks","Grade"]])

Output:
